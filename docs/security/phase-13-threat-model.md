# Phase 13 威胁模型

## 目标与边界

应用锁用于阻止普通的临时借机查看；保险库用于保护应用私有存储中的媒体内容和元数据。二者是独立控制：应用锁 PIN 不作为媒体加密密钥，也不冒充 Android Keystore。

受保护资产包括视频明文、原文件名与 MIME 元数据、保险库索引、密钥别名、播放画面和会话状态。边界包括应用进程、Android Keystore、`noBackupFilesDir/vault`、Room 匿名索引、Media3 数据源、窗口和系统通知。

## 威胁与控制

| 威胁 | 控制 | 剩余风险 |
| --- | --- | --- |
| 丢机、离线读取应用文件 | Keystore AES-256 密钥；分块 AES-GCM；备份与设备迁移全部排除 | 已解锁且被攻陷的设备不在保证范围 |
| 密文篡改、截断、重排、错密钥 | 每块独立认证；manifest、块序号和长度进入 AAD；任一认证失败使 reader 永久失效 | 不提供损坏内容恢复 |
| 暴力猜测应用 PIN | PBKDF2-HMAC-SHA256、随机 salt、常量时间比较、失败限速 | PIN 强度仍由用户选择决定 |
| 后台、最近任务、截图、PiP 泄露 | 锁页、保险库和安全播放器启用 `FLAG_SECURE`；安全播放器隐藏截图/PiP；进后台停止安全会话 | OEM 对系统 UI 的实现差异需真机审计 |
| 通知、历史、迷你播放器泄露 | 安全播放强制 incognito、匿名媒体 ID/标题；锁定立即停止；保险库路由不显示迷你播放器 | 停止前系统可能短暂显示匿名通知 |
| 导入/导出中断 | 密文 `.part` 写完并反向验证后再提交；失败清理临时密文；导出失败请求删除半成品 | 外部文档提供者可能不支持可靠删除 |
| 原路径或标题进入数据库/日志 | Room 仅保存随机 ID 和匿名文件 token；metadata 单独加密；错误只暴露稳定代码 | 导出目标由用户选择，离开保护边界后由用户负责 |
| 密钥失效或设备锁移除 | 返回明确不可用/永久失效状态，不静默生成替代密钥 | 当前没有恢复密钥，数据可能永久不可恢复 |

## 非目标

不防御 root、内核或应用进程注入、已解锁设备上的内存取证、屏幕外部拍摄，也不承诺 NAND/闪存物理擦除。应用卸载、Keystore 密钥失效或设备故障后无法恢复保险库；产品必须明确告知这一点。

## 验收

自动化覆盖 PIN 正误、限速、后台超时与时钟回拨；多块往返、随机 seek、篡改、截断、尾随数据和错密钥；Room v5→v6；锁页和删除确认 Compose 状态。Keystore 失效、最近任务、通知、截图、PiP、长视频 seek 和导入导出中断仍需目标设备仪器/人工演练。
