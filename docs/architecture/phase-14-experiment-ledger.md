# Phase 14 实验台账

## 证据门禁

每个提案必须包含真实问题、代表且隐私获批的样本、可测成功指标、许可证结论、安全审批、负责人和退出策略。`ExperimentGate` 对缺样本、非代表样本、隐私未批准、许可证不兼容、缺指标或安全未批准自动给出 No-Go；指标不能覆盖许可证、隐私或安全失败。

| 提案 | 结论 | 当前证据 | 重新评估条件 |
| --- | --- | --- | --- |
| GIF/动图导出 | No-Go | 无时长/尺寸/色彩/体积代表样本，无 OOM 与质量基线 | 样本获批并冻结时间、内存、质量、体积指标 |
| 片段级相似去重 | No-Go | 无局部复用标注集、precision/recall 和人工复核成本 | 建立隐私获批标注集且误报不能形成自动删除 |
| 第二播放内核 | No-Go | 未收集 Media3 无法播放的合法代表样本 | 真实失败率足够且候选通过同一 Playback Contract |
| FFmpeg 后端 | No-Go | 无平台 Transformer 失败任务集，无 ABI/包体/功耗/CVE 与 LGPL/GPL 审核 | 法务、供应链、安全和量化收益同时过门槛 |
| 网络源 | No-Go | 产品仍为纯本地定位，无协议、认证、DRM、缓存和隐私需求证据 | 产品需求成立且安全/隐私 ADR 获批 |

本阶段不新增生产依赖、UI 入口、native 二进制或远程权限。所有结论可在补齐证据后重新提交提案；Spike 不能直接进入 release source set。
