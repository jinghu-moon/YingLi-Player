# Phase 7 高级播放与系统集成契约

## 控制布局

```text
顶部：返回 | 标题 | 截图 | 画中画
中部：后退 10 秒 | 播放/暂停 | 前进 10 秒
底部：进度/时间 | 倍速与轨道面板 | 旋转 | 锁定
```

单击切换控制层，双击左/右半区固定后退/前进 10 秒。3 秒无交互后自动隐藏；拖动期间不隐藏；锁定后只保留解锁动作。控制层使用黑色 72% 边缘 Scrim，主要、次要内容使用白色层级，不使用功能色表达播放状态。

## 偏好与队列

- 固定倍速：0.5、0.75、1、1.25、1.5、2、3、4 倍；其他值在领域层拒绝。
- 单视频偏好覆盖全局偏好；缺失或损坏值回退 1 倍、字幕关闭、FIT。
- 画面模式：FIT、FILL、ORIGINAL。
- 队列必须显式设置；连续播放默认关闭，因此队列有下一项也不会自动播放。
- 迷你播放器默认开启配置项；关闭只隐藏应用内控制条，不终止 MediaSession 或通知。

## 系统集成矩阵

| 能力 | 实现 | 回退 |
| --- | --- | --- |
| 音频焦点 | ExoPlayer AudioAttributes 管理焦点 | 拒绝焦点时不自动播放 |
| 耳机断开 | `setHandleAudioBecomingNoisy(true)` | 自动暂停，由会话保持状态 |
| 通知/按键 | 唯一 MediaSessionService | Controller 重连复用会话 |
| 画中画 | Activity 主动入口；自动 PiP 默认关闭 | 不支持时留在播放页 |
| 旋转 | Activity 请求传感器横屏/恢复未指定 | MediaSession 保留位置 |
| 截图 | PlayerView Surface/Texture + PixelCopy/Bitmap | 空帧、权限、空间失败均不暂停播放 |

## 截图输出

截图在 I/O Dispatcher 编码为 JPEG 92，保存到 `Pictures/YingLi`。文件名由脱敏后的视频名、播放毫秒位置和时间戳组成；MediaStore 生成新条目，不覆盖同名文件。结果只向 UI 返回展示名或稳定失败分类，不暴露内容 URI。

## 验证范围

JVM 覆盖偏好优先级、倍速边界、队列末尾和 Overlay 状态机；Compose 覆盖锁定/解锁、动态播放语义和设置面板；Media3 仪器覆盖单例会话、高级偏好命令；截图与多轨真实样本结果在真机媒体矩阵中记录。
