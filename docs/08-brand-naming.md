# 影里品牌与命名规范

> 状态：Final 01
>
> 决策日期：2026-08-06

## 1. 最终名称

| 使用位置 | 名称 |
| --- | --- |
| 中文主品牌 | 影里 |
| App 桌面名称 | 影里 |
| 英文短标 | YingLi |
| 完整产品描述 | 影里 - 本地视频播放器与媒体库 |
| GitHub 仓库 | `jinghu-moon/YingLi-Player` |
| 本地项目目录 | `YingLi-Player` |
| 默认处理输出目录 | `YingLi-Output` |

Android namespace 和 applicationId 统一使用 `seeyuer.yingli.player`。包名必须全小写且不能包含连字符；仓库名中的 `-Player` 只是功能描述，不属于应用内品牌。

## 2. 命名依据

影里首先是一款用于观看本地视频的软件。用户最高频的行为是找到视频、开始播放、续播和完成观看；分类、标签、文件管理及后续视频处理用于提高长期使用效率，但不应压过观看这一主语义。

“影”直接指向视频、电影和影像内容；“里”表达个人内容所在的空间，整体可以自然理解为“在影像之中”或“视频都在这里”。“里”是方位关系，不像“序”那样成为需要额外解释的抽象核心词。名称保持中性，不把产品限制为纯播放器、文件管理器、专业剪辑器或隐私保险库。

“影里”还可以与“书里”形成一致的产品家族：前者服务本地视频观看，后者服务阅读。两者共享亲切、个人、本地优先的品牌气质，但功能和数据保持独立。

## 3. 产品定位表达

首次正式介绍使用以下表述：

> 影里（YingLi Player）是一款面向 Android 的本地视频播放器与个人媒体管理中心，优先提供轻快、稳定的观看体验，并支持搜索、筛选、标签、集合、安全文件管理及后续视频处理。

推荐品牌标语：

> 喜欢的影像，都在这里。

需要强调本地与隐私时，可以使用：

> 自己的视频，安心看。

## 4. 使用规则

- 应用图标、桌面名称、页面标题和用户文案统一使用“影里”；
- 文档首次出现时可以使用“影里（YingLi Player）”，后续只使用“影里”；
- `YingLi` 仅用于拉丁字母短标、代码标识和不支持中文的场景；
- 不使用 `YingLiPlay` 作为品牌，它是为满足字符数而截断的功能短语，辨识度和完整性均弱于 `YingLi`；
- `YingLi-Player` 或 `yingli-player` 只用于项目目录、GitHub 仓库和需要说明产品类型的技术场景；
- 历史名称不再用于现行品牌、代码示例或输出目录；现行标识统一使用“影里”、`YingLi` 和 `YingLi-Player`。

## 5. 候选名称结论

| 候选 | 结论 |
| --- | --- |
| 映序 | “序”成为语义重心，但无法直接传达视频观看，不采用。 |
| 览影 | 能表达浏览和媒体库，但相对放大了低频管理行为，不作为主品牌。 |
| 理影 | 精确对应整理能力，但容易被理解为视频整理工具。 |
| 存影 | 强调留存、回收站和保险库，偏离高频观看行为。 |
| 悦影 | 观看语义明确，但情绪性较强，缺少个人内容空间的延展性。 |
| 畅影 | 能表达播放性能，但容易把品牌限制为纯播放器。 |
| 帧序 | 适合视频处理引擎或技术模块，不适合普通用户主品牌。 |
| 影里 | 观看语义明确、气质中性、能够承载媒体库和后续能力，最终采用。 |

## 6. 品牌与功能边界

品牌名称只负责建立“个人本地视频观看空间”的第一认知，不承担完整功能清单。整理继续作为一级页面名称，切片、压缩、转换和去重进入处理中心，应用锁与加密保险库作为后续安全能力。这样可以保证品牌稳定，同时让功能通过信息架构清晰呈现。
