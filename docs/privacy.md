# 隐私说明

## 数据处理

影里以本地优先方式工作。媒体索引、标签、集合、播放历史、片段项目和处理任务保存在应用私有 Room 数据库与 Preferences DataStore 中。视频内容不会因为播放、整理或处理而上传。

## 权限

- 视频读取权限用于发现用户允许访问的本地视频。
- SAF 和“全部文件访问”仅在用户主动选择对应来源时打开系统授权页面。
- 通知权限用于媒体播放和用户主动发起的处理任务。
- 网络权限只用于用户主动执行 GitHub Release 更新检查，固定访问 `api.github.com`。

拒绝任一可选权限时，应用保留其他本地功能并提供 SAF 等替代入口。

## 诊断与备份

- 诊断报告只在用户主动导出时生成，不会自动发送。
- 日志使用稳定错误码并脱敏，不包含原始文件路径、内容 URI、文件名、视频帧和密钥。
- 备份可包含设置、标签/集合关系和播放历史；自定义目录授权 URI 不进入备份。
- 备份格式在开发阶段只保证当前 schema 版本，不承诺跨开发版本兼容。

## 网络与遥测

应用不接入广告、分析、崩溃上传或网络媒体 SDK，不收集硬件标识，不允许明文 HTTP。
